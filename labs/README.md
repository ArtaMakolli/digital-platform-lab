# Labb 1–9: så använder du dem

Labbarna görs först med stöd i undervisningen och kan sedan upprepas individuellt. De använder samma lilla app i detta repo. Gruppens valfria projekt och musikspelaren är separata tillämpningar av samma idéer.

**Arbetssätt i varje labb:** Förutsäg → prova en sak → observera i sidan, DevTools och terminalen → förklara vad observationen visar → återställ avsiktliga fel. Ett svar från servern bevisar bara det som svaret faktiskt säger.

| Labb | Tema | Koppling till lektion |
| --- | --- | --- |
| [01](01-dataflow/README.md) | Miljö, localhost, klient/server och Network | Lektion 1 |
| [02](02-html/README.md) | HTML och DOM | Lektion 2 |
| [03](03-javascript-events/README.md) | JavaScript-händelser och eventobjekt | Lektion 2 och 4 |
| [04](04-browser-storage/README.md) | Webbläsarens lagring | Lektion 5 |
| [05](05-identification/README.md) | Identifiering och dess gränser | Lektion 6 |
| [06](06-tracking/README.md) | Datalager, tracking och request | Lektion 7 |
| [07](07-consent/README.md) | Samtycke som tekniskt tillstånd | Lektion 8 |
| [08](08-client-server/README.md) | Klientens request och serverns kvitto | Lektion 8 |
| [09](09-debugging/README.md) | Systematisk felsökning | Lektion 9 |

**Lektionsnummer och labbnummer är inte samma sak.** Exempelvis hänvisar lektion 4 till labb 03, lektion 5 till labb 04 och lektion 6 till labb 05. Labb 1–3 kan användas som repetition om teknikstrul gjorde att du missade någon del.

Starta alltid i projektets rotmapp med `npm.cmd start` i Windows PowerShell eller `npm start` på macOS/Linux/Codespaces. Öppna `http://localhost:3000` lokalt, eller den vidarebefordrade porten i Codespaces. Ingen installation av externa npm-paket krävs.
